犬との暮らし研究所 - Netlify / GitHub用スターター

1. このフォルダの中身（index.html と images フォルダ）をGitHubリポジトリのルートにアップロードしてください。
2. Netlifyの設定は次の通りです。
   - Branch to publish: main
   - Base directory: 空欄（/ の表示でも通常はルート）
   - Build command: 空欄
   - Publish directory: .
3. GitHubへファイルを追加した後、NetlifyでDeployを開始してください。
